# Gbadelawal_kolade_engineering_unit_Engineering Unit Converter

What it does

The Engineering Unit Converter is a Python program that converts different engineering measurements from one unit to another. It converts millimetres and inches, Celsius and Fahrenheit, kilograms and pounds, and kilometres per hour and metres per second. The program uses a menu that allows users to select the conversion they want to perform.

How to run it

Install Python 3, then run:

python unit_converter.py

The program can also be run using Pydroid 3 on an Android phone.

My own twist

I added two special features to my Engineering Unit Converter.

1. Reverse Conversion: The program allows users to convert measurements in both directions. For example, users can convert millimetres to inches and inches to millimetres.
2. Conversion History: The program stores previous conversions in a list. Users can view their conversion history or clear it whenever they want.
